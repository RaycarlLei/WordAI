# WordAI Community

免费的开源单词学习应用。使用 Flutter 和本地 SQLite，默认无需账号、订阅或服务器。

这是 WordAI 的社区版，导入了当前产品的学习与 Flash Card 核心，并采用独立、干净的 Git 历史。它不是生产版的完整镜像：账号、云同步、AI 查词、支付、生产词库下载与部署配置不包含在内。

## 已包含

- 本地学习记录、词义级进度、例句与独立识别两个阶段。
- 从本地已导入的全部词义中选择干扰选项，避免“题目不足”误报为“全部学完”。
- 每题自动发音，优先本地音频缓存；可选自建 HTTPS 语音网关；失败时尝试设备语音。
- 12 个原创示例词；导入自己有权使用的 S6 格式 JSON 词条。
- 导出本机学习备份，完整校验后用一个事务恢复词汇、进度和答题历史。
- 英文、简体中文和繁体中文复习界面；减少动态效果支持。

## 运行

安装 Flutter 3.44 或更新的 stable 版本（Dart 3.6 或更新），然后：

```sh
flutter pub get
flutter run
```

原生工程包含 Android、iOS、macOS。iOS/macOS 真机签名由开发者自行配置；仓库没有个人签名团队、证书或生产服务配置。平台支持以实际构建和测试结果为准。

```sh
flutter analyze
flutter test
python3 scripts/check_public_tree.py
```

## 导入词条

首页选择“导入词库”。文件可以是一个词条对象或数组，采用 `lib/services/wordai_dossier.dart` 定义的 S6 schema。整个文件先验证，再写入本地数据库；实际读取上限 10 MiB / 20,000 条，空文件、空数组和没有学习内容的查词结果不能导入。重复导入更新内容并保留学习进度。导入过程中发生存储错误时，已完成的词条会保留，可以重试。

首页仅在本机词库为空时初始化示例词。恢复备份后，刷新和重新打开应用都不会补入其他示例词，也不覆盖导入内容或学习进度。CI 使用 Flutter 3.44.0 和 3.47.2 分别运行分析与测试，后者同时生成可下载的 Android debug APK；该产物用于开发验证，尚非商店签名发行版。

示例：`examples/words.json`。请确认导入内容的分发与使用许可。生产环境的第三方词库和音频没有随本仓库分发。

未回答的题目会在计分事务中核对已保存选项和当前内容；导入改变题目内容后，页面会重新出题。临时数据库错误保留轮次供重试。数据库从 schema 3 升级到 4 时保留已有进度，旧题快照会在再次使用时重建。设计与磁盘回归测试见 [持久化题目说明](docs/persisted-review.md)。

## 备份学习数据

选择“学习备份 → 保存备份”，将本机词汇、词义级进度和答题历史保存到自己选择的文件。“从文件恢复”会先校验完整备份（最大 32 MiB），展示日期和记录数量。确认“替换本机学习数据”后才替换当前数据；需要保留当前数据时，请先另存备份。未完成的轮次会结束，下一轮根据恢复的内容重新出题。

备份为可读的 JSON 文件，请放在私密位置。它保存学习所用的数据，不包含原始 S6 文件的全部内容、设置或音频。Android 使用系统文档选择器，iOS 使用系统文档导出器，桌面使用平台文件对话框。保存失败可能留下不完整文件；iOS 导出确认也不代表云端同步完成。具体格式、上限和失败行为见 [备份与恢复说明](docs/learning-backup.md)。

这个功能不能让新签名的 APK 自动访问旧安装的数据。不同构建的 debug APK 可能使用不同签名；在取得可用备份之前，请保留旧安装及数据。社区发行版仍是开发构建，尚未配置稳定的分发签名。

## 可选语音网关

默认不联系网络服务。设备离线语音是否可用取决于系统安装的语音包。需要下载发音时，自行实现 [网关协议](docs/speech-gateway.md)，再显式配置自己的地址：

```sh
flutter run --dart-define=WORD_AI_API_BASE_URL=https://your-gateway.example
```

该地址会编译进客户端，只能放非敏感的服务地址。供应商密钥只能保存在服务端。使用自建网关时，当前需要发音的文字会发送给该网关；失败不会阻止本地学习。

发音协调器区分界面状态与原生播放归属，隔离旧播放器事件，并为每次原生调用设置期限。超时后会尝试停止音频，页面仍可继续答题；本次应用会话不再启动新的音频。具体保证、插件限制和设备验证范围见 [音频生命周期说明](docs/audio-lifecycle.md)，回归入口为 [实际服务测试](test/tts_service_lifecycle_test.dart)。

## 本地单词本与最近删除

打开「单词本」可新建、重命名、添加已导入词条，并只复习所选单词本。
「默认单词本」收录新导入的词条；全部词义学会后，词条自动加入「已学会」。
这两个单词本不可删除；「不熟悉的」和自建单词本可以删除。
从单词本移除词条不会删除词典内容或学习进度。从「已学会」手动移除后，
普通刷新不会重新加入；重新学会一个词义或手动添加时才会加入。

「最近删除」在本机保留删除的单词本和移除的词条 7 天。
恢复按单词本标识合并、词条去重，不会合并同名的其他单词本。
打开回收站时清理到期内容；永久删除需要确认。

0.2.0 使用 SQLite 结构版本 5 和备份格式 2，备份包含单词本、回收记录和手动移除状态。
仍可恢复格式 1 的旧备份，恢复后初始化系统单词本；这会替换当前单词本。
旧版应用不能读取新数据库或格式 2 备份。升级前请保存备份。

默认不连接任何账号、同步、AI 或遥测服务，不提供考试词库下载和生产资源。
