# 开源范围

公开仓库维护可独立运行的本地学习核心与示例应用。私有仓库继续维护线上产品，两者不共享 Git 历史，也不通过合并私有分支来发布。

| 内容 | 社区版处理 |
| --- | --- |
| 学习状态机、题目生成、Flash Card 界面、缓存发音 | 开放源码与回归测试 |
| SQLite 数据层、S6 词条解析、原创示例词 | 开放源码 |
| 可选语音服务 | 空配置，公开协议，由使用者自建 |
| 账号、云同步、计费、分析、生产 AI 服务 | 不包含 |
| 生产地址、项目标识、密钥、签名、部署脚本、内部文档 | 不导入 |
| 第三方大词库、预生成音频 | 不分发，另行核对许可 |

## 后续更新

1. 在独立目录中挑选私有版的通用改动，并移除线上服务耦合。
2. 保留作者与第三方许可，补齐社区版的必要接口和说明。
3. 执行静态检查、回归测试、平台构建、敏感信息检查及人工审阅。
4. 只提交社区目录内审核过的文件。不得推送私有 Git 对象、备份、原始审计报告或生产日志。

默认运行不连接生产服务，不自动下载付费或大容量资源。公开源码不代表免费提供托管计算和第三方语音服务。
