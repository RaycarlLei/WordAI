# Third-party notices

The eight outline icons in `assets/reicon` are a selected subset of [Reicon](https://github.com/dqev/reicon), from commit `80d6547e46bd3074b8d7fe6682f604c6c89d91a8`. Their path geometry is unchanged; SVG wrappers set a 24-pixel view box and a tintable black fill. The official Dart package uses a shared catalog map, so this app vendors only the selected glyphs.
